## 2. Математическая формализация

### 2.1 TSP для диссертаций (Звено 2)

**Документ**: `dissertation_tsp_theory.md` (1095 строк, ~45KB)

#### 2.1.1 Основная модель

**Диссертация как граф**:
```python
D = (V, E, W, C)

где:
- V = {v₁, v₂, ..., vₙ} — тематические блоки (главы)
- E ⊆ V × V — возможные переходы
- W: E → ℝ⁺ — когнитивная дистанция
- C: V → ℝ⁺ — стоимость создания блока
```

#### 2.1.2 Когнитивная дистанция

**Многомерная метрика**:
```python
d(vᵢ, vⱼ) = α·d_semantic(vᵢ, vⱼ) +    # Семантика
            β·d_temporal(vᵢ, vⱼ) +    # Хронология
            γ·d_logical(vᵢ, vⱼ) +     # Логика
            δ·d_reader(vᵢ, vⱼ)        # Читательская нагрузка

где α + β + γ + δ = 1
```

**Компоненты**:

1. **Семантическое расстояние** (d_semantic):
   - Тематическое моделирование (LDA)
   - Дивергенция Йенсена-Шеннона
   - Векторные представления (BERT, GPT)
   ```python
   d_semantic(vᵢ, vⱼ) = D_JS(θᵢ || θⱼ)  # JS divergence
   # или
   d_semantic(vᵢ, vⱼ) = 1 - cos_sim(emb(vᵢ), emb(vⱼ))
   ```

2. **Временное расстояние** (d_temporal):
   - Хронологический порядок событий
   - Разрыв в timeline

3. **Логическая дистанция** (d_logical):
   - Граф зависимостей G_logic = (V, E_logic)
   - Типы: Определение→Использование, Проблема→Решение, Метод→Применение
   ```python
   d_logical(vᵢ, vⱼ) = shortest_path(vᵢ, vⱼ) / diameter(G_logic)
   ```

4. **Читательская нагрузка** (d_reader):
   - Модель когнитивной нагрузки Свеллера
   ```python
   CL_reader = CL_intrinsic + CL_extraneous + CL_germane
   ```

#### 2.1.3 Задача оптимизации

```python
minimize: J(π) = Σᵢ₌₁ⁿ⁻¹ d(π(i), π(i+1)) + λ·Σᵢ₌₁ⁿ p(π(i))

при ограничениях:
1. π — перестановка множества V
2. s_start ∈ {π(1)} (введение первым)
3. s_end ∈ {π(n)} (заключение последним)
4. ∀i: prerequisite(π(i)) ⊆ {π(1), ..., π(i-1)}
```

#### 2.2.1 Классическая TSP
- **Применение**: Оптимизация порядка глав верхнего уровня

- **Статус**: ✅ Теория полная, код есть

- **Применение**: Оптимизация на 3 уровнях (главы → разделы → параграфы)
- **Статус**: ✅ Теория полная, код частично

- **Статус**: ✅ Теория полная, код нет

- **Применение**: Строгие логические зависимости
- **Граф ограничений**: poset (частично упорядоченное множество)
- **Статус**: ✅ Теория полная, код есть

#### 2.2.6 Динамическая TSP (Dynamic TSP)
- **Применение**: Адаптация по мере написания
- **Модель**: V(t), d(i,j,t) меняются со временем
- **Статус**: ✅ Теория полная, код нет

#### 2.2.7 Stochastic TSP (вероятностная)
- **Применение**: Учет неопределенности
- **Модель**: C(vᵢ) ~ Normal(μᵢ, σᵢ²), d ~ LogNormal
- **Статус**: ✅ Теория полная, код нет

## 3. Методы оптимизации и улучшения

### 3.1 Точные алгоритмы (N < 15)

#### 3.1.1 Динамическое программирование (Held-Karp)

**Сложность**: O(n² · 2ⁿ)

```python
def dissertation_dp(V, d, start, end):
    """
    Точное решение через DP
    dp[mask][i] = минимальная стоимость маршрута
    """
    n = len(V)
    dp = [[inf] * n for _ in range(1 << n)]
    parent = [[-1] * n for _ in range(1 << n)]

    # Начало: только start посещён
    dp[1 << start_idx][start_idx] = 0

    # Заполнение таблицы DP
    for mask in range(1 << n):
        for last in range(n):
            if not (mask & (1 << last)):
                continue
            if dp[mask][last] == inf:
                continue

            for next in range(n):
                if mask & (1 << next):
                    continue

                # Проверка зависимостей
                if not dependencies_satisfied(mask, next, dependencies):
                    continue

                new_mask = mask | (1 << next)
                new_cost = dp[mask][last] + d[last][next]

                if new_cost < dp[new_mask][next]:
                    dp[new_mask][next] = new_cost
                    parent[new_mask][next] = last

    # Восстановление пути
    full_mask = (1 << n) - 1
    return reconstruct_path(parent, full_mask, end_idx)
```

**Статус**: ✅ Реализовано в `dissertation_optimizer.py`

#### 3.1.2 Branch & Bound

**Идея**: Отсекаем заведомо неоптимальные ветви

```python
def branch_and_bound_tsp(V, d, dependencies):
    """
    Метод ветвей и границ
    """
    best_solution = None
    best_cost = inf

    def bound(partial_path, remaining):
        """Нижняя граница для текущего пути"""
        # MST на remaining + текущий путь
        return current_cost + mst_bound(remaining, d)

    def branch(partial_path, remaining, current_cost):
        nonlocal best_solution, best_cost

        if not remaining:
            # Завершили путь
            if current_cost < best_cost:
                best_solution = partial_path
                best_cost = current_cost
            return

        # Вычисляем нижнюю границу
        lower_bound = bound(partial_path, remaining)
        if lower_bound >= best_cost:
            # Отсекаем ветвь
            return

        # Ветвимся по каждому следующему узлу
        for next_node in remaining:
            if dependencies_ok(partial_path, next_node):
                new_cost = current_cost + d[partial_path[-1]][next_node]
                branch(
                    partial_path + [next_node],
                    remaining - {next_node},
                    new_cost
                )

    branch([start], set(V) - {start, end}, 0)
    return best_solution, best_cost
```

**Статус**: ⚠️ Теория есть, код НЕТ

### 3.2 Эвристические алгоритмы (N > 15)

#### 3.2.1 Greedy (жадный)

**Сложность**: O(n²)

```python
def greedy_with_constraints(V, d, dependencies, start, end):
    """
    Жадный алгоритм с учетом зависимостей
    """
    current = start
    path = [start]
    remaining = set(V) - {start, end}

    while remaining:
        # Выбираем ближайший доступный узел
        best_next = None
        best_dist = inf

        for node in remaining:
            # Проверяем зависимости
            if all(dep in path for dep in dependencies.get(node, [])):
                dist = d[current][node]
                if dist < best_dist:
                    best_dist = dist
                    best_next = node

        if best_next is None:
            # Тупик - нарушены зависимости
            raise ValueError("Cannot satisfy dependencies")

        path.append(best_next)
        remaining.remove(best_next)
        current = best_next

    path.append(end)
    return path
```

**Статус**: ✅ Реализовано

#### 3.2.2 2-opt локальная оптимизация

**Идея**: Пробуем переставить пары рёбер

```python
def two_opt_optimize(path, d, dependencies):
    """
    Улучшение маршрута методом 2-opt
    """
    improved = True

    while improved:
        improved = False

        for i in range(1, len(path) - 2):
            for j in range(i + 1, len(path) - 1):
                # Проверяем зависимости
                if not check_dependencies_after_reversal(path, i, j, dependencies):
                    continue

                # Текущие рёбра: (i-1, i) и (j, j+1)
                # Новые рёбра: (i-1, j) и (i, j+1)
                old_cost = d[path[i-1]][path[i]] + d[path[j]][path[j+1]]
                new_cost = d[path[i-1]][path[j]] + d[path[i]][path[j+1]]

                if new_cost < old_cost:
                    # Обращаем сегмент [i, j]
                    path[i:j+1] = reversed(path[i:j+1])
                    improved = True
                    break

            if improved:
                break

    return path
```

**Статус**: ✅ Реализовано

#### 3.2.3 Simulated Annealing (имитация отжига)

**Идея**: Метаэвристика с вероятностным принятием ухудшений

```python
def simulated_annealing_dissertation(V, d, dependencies,
                                     T_init=1000, alpha=0.95, max_iter=10000):
    """
    Имитация отжига для оптимизации
    """
    # Начальное решение
    current = greedy_with_constraints(V, d, dependencies, V[0], V[-1])
    current_cost = path_cost(current, d)

    best = current.copy()
    best_cost = current_cost

    T = T_init

    for iteration in range(max_iter):
        # Генерируем соседа
        neighbor = generate_neighbor(current, dependencies)
        neighbor_cost = path_cost(neighbor, d)

        # Принятие решения
        delta = neighbor_cost - current_cost

        if delta < 0:
            # Улучшение — всегда принимаем
            current = neighbor
            current_cost = neighbor_cost

            if current_cost < best_cost:
                best = current.copy()
                best_cost = current_cost
        else:
            # Ухудшение — принимаем с вероятностью exp(-delta/T)
            acceptance_prob = exp(-delta / T)
            if random() < acceptance_prob:
                current = neighbor
                current_cost = neighbor_cost

        # Охлаждение
        T *= alpha

        if T < 0.01:
            break

    return best, best_cost
```

**Стратегии генерации соседей**:
1. **swap**: Меняем местами две главы
2. **reversal**: Обращаем сегмент
3. **insert**: Извлекаем и вставляем в другое место

**Статус**: ✅ Реализовано

def ant_colony_optimization(V, d, dependencies, n_ants=50, n_iterations=100):
    """
    Оптимизация муравьиной колонии
    """
    # Инициализация феромонов
    pheromone = initialize_pheromone(V)

    best_path = None
    best_cost = inf

    for iteration in range(n_iterations):
        paths = []

        # Каждый муравей строит путь
        for ant in range(n_ants):
            path = construct_path(V, d, pheromone, dependencies)
            paths.append(path)

            cost = path_cost(path, d)
            if cost < best_cost:
                best_path = path
                best_cost = cost

        # Обновление феромонов

        # Испарение
        pheromone *= (1 - evaporation_rate)

```python
class SmartQuestLog:
    """
    Оптимизация порядка выполнения квестов
    """
    def optimize_quest_order(self, quests, player_location):
        # Прямое применение TSP!
        # Квесты = города
        # Расстояния = время пути + сложность

        distances = self._compute_quest_distances(quests, player_location)
        optimal_order = tsp_solver.solve(quests, distances)

        return optimal_order

    def _compute_quest_distances(self, quests, location):
        """
        Когнитивная дистанция между квестами
        (аналогично диссертациям!)
        """
        d = {}
        for qi in quests:
            for qj in quests:
                d[(qi, qj)] = (
                    alpha * spatial_distance(qi, qj) +      # Физическое расстояние
                    beta * difficulty_distance(qi, qj) +    # Разница в сложности
                    gamma * theme_distance(qi, qj) +        # Тематическое расстояние
                    delta * prerequisite_distance(qi, qj)   # Зависимости
                )
        return d
```

**Связь**: TSP (Звено 1) → Диссертации (Звено 2) → Квесты (Звено 5)
