## 🎯 Концепция проекта

Создана комплексная система для **двунаправленной трансформации научных знаний** между специализированными источниками (диссертации) и обобщенными (энциклопедии).

```
Направление 1: Диссертации → Энциклопедия
┌──────────────┐  decompose  ┌──────────┐  aggregate  ┌──────────────┐

┌──────────────┐  decompose  ┌────────┐  synthesize  ┌──────────────┐

│ Статья 3     │─────────────→│        │─────────────→│ Диссертация  │
└──────────────┘              └────────┘              └──────────────┘

Рационализация: Оптимизация представления знаний
```

### 1. Теоретическая основа (50 KB)

**`knowledge_transformation_theory.md`**

**Содержание:**

#### Математическая формализация
- Граф научных знаний G = (V, E, T, A, C, R)
- Диссертация как подграф D = (V_D, E_D, M_D)
- Энциклопедическая статья W = (V_W, E_W, M_W)

#### Направление 1: Диссертации → Энциклопедия
```
Декомпозиция: D → {S₁, S₂, ..., Sₖ} (сегменты)

Агрегация: maximize Q(W) = α·Coverage + β·Coherence + γ·Diversity - δ·Redundancy
```

**Метрики:**
- Information Coverage (IC)
- Source Diversity (SD)
- Novelty Preservation (NP)
- Citation Accuracy (CA)

#### Направление 2: Энциклопедия → Диссертации
```
Декомпозиция: W → {F₁, F₂, ..., Fₘ} (факты)

Синтез: maximize Q(Path) = α·Novelty + β·Impact + γ·Feasibility - δ·Redundancy
```

**Алгоритмы:**
- Идентификация пробелов в знаниях
- Генерация исследовательских гипотез
- Построение структуры диссертации

#### Рационализация научного знания

**Типы:**
1. **Компрессионная** — удаление избыточности
2. **Структурная** — оптимизация структуры
3. **Семантическая** — устранение противоречий

**Информационно-теоретический подход:**
```
minimize: K(K') subject to I(K, K') ≥ (1-ε)·I(K)

где K(·) — Колмогоровская сложность
    I(·) — информационное содержание
```

**Теоремы:**
- О минимальной рационализации
- О NP-трудности оптимальной рационализации
- О сохранении информации при трансформации

#### Связь с TSP

Оптимизация структуры энциклопедической статьи = TSP!
```
minimize: J(π) = Σᵢ₌₁ⁿ⁻¹ cognitive_distance(π(i), π(i+1))
```

Применимы все алгоритмы из `dissertation_optimizer.py`.

## 🔬 Ключевые алгоритмы

### Алгоритм 1: Декомпозиция диссертации

```
FUNCTION decompose_dissertation(D):
    1. Разбить на параграфы
    2. Кластеризовать по темам (LDA)
    3. Извлечь концепты (NER + термины)
    4. Извлечь связи (co-occurrence)
    5. Сформировать сегменты

    RETURN segments[]
```

**Сложность:** O(n·k), где n — параграфы, k — концепты

### Алгоритм 2: Агрегация в энциклопедию

```
FUNCTION aggregate_to_encyclopedia(segments[], topic):
    1. Построить граф концептов
    2. Кластеризовать концепты (компоненты связности)
    3. Выбрать центральные (PageRank)
    4. Построить структуру статьи
    5. Сгенерировать текст с цитированиями

    RETURN encyclopedia_article
```

**Оптимизация:** Выбор центральных концептов = задача доминирующего множества (NP-трудная)

**Приближенный алгоритм:** Жадный выбор по PageRank

### Алгоритм 3: Синтез диссертации из энциклопедий

```
FUNCTION synthesize_dissertation(wiki_articles[]):
    1. Извлечь факты из статей (SPO триплеты)
    2. Построить граф знаний
    3. Идентифицировать пробелы:
       - Отсутствующие связи
       - Недоисследованные концепты
    4. Сгенерировать гипотезы:
       - О новых связях
       - О новых свойствах
    5. Построить структуру диссертации:
       - Введение (мотивация)
       - Обзор литературы (существующее знание)
       - Методология (как проверить гипотезу)
       - План исследования

    RETURN dissertation_proposal
```

### Алгоритм 4: Рационализация знаний

```
FUNCTION rationalize(K):
    # Компрессионная рационализация
    1. Кластеризовать похожие концепты
    2. Объединить кластеры (выбрать представителя)
    3. Удалить избыточные связи
    4. Обобщить (индукция правил)

    # Семантическая рационализация
    5. Выявить противоречия
    6. Разрешить:
       - По достоверности источников
       - По свежести информации
       - Контекстуализация

    # Структурная рационализация
    7. Иерархизировать (таксономия)
    8. Модуляризировать
    9. Оптимизировать порядок (TSP!)

    RETURN K_rationalized
```

## 📊 Метрики качества

### Направление 1: Диссертации → Энциклопедия

| Метрика | Формула | Интерпретация |
|---------|---------|---------------|
| **Information Coverage** | IC = \|V_W ∩ (⋃V_Di)\| / \|⋃V_Di\| | Доля сохраненной информации |
| **Source Diversity** | SD = -Σpᵢlog(pᵢ) | Равномерность источников |
| **Novelty Preservation** | NP = \|novel(W)\| / \|novel(⋃Di)\| | Сохранение новых концептов |
| **Citation Accuracy** | CA = correct_cit / total_cit | Точность цитирований |

**Целевые значения:**
- IC ≥ 0.8 (сохранить 80%+ информации)
- SD ≥ 0.7 (высокое разнообразие)
- NP ≥ 0.6 (сохранить 60%+ новизны)
- CA ≥ 0.95 (95%+ точность)

### Направление 2: Энциклопедия → Диссертации

| Метрика | Формула | Интерпретация |
|---------|---------|---------------|
| **Novelty Score** | NS = avg(novelty(c)) for c in D' | Степень новизны |
| **Gap Coverage** | GC = \|covered_gaps\| / \|total_gaps\| | Закрытие пробелов |
| **Hypothesis Strength** | HS = avg(testability · impact · support) | Сила гипотез |
| **Feasibility Score** | FS = geomean(data, methods, resources, time) | Выполнимость |

**Целевые значения:**
- NS ≥ 0.7 (высокая новизна)
- GC ≥ 0.5 (закрыть 50%+ пробелов)
- HS ≥ 0.6 (сильные гипотезы)
- FS ≥ 0.7 (выполнимо)

### Рационализация

| Метрика | Формула | Цель |
|---------|---------|------|
| **Compression Ratio** | CR = Size(K') / Size(K) | Minimize |
| **Information Loss** | IL = 1 - I(K,K')/I(K) | < ε (обычно 0.1) |
| **Accessibility Gain** | AG = Access(K') / Access(K) | Maximize |
| **Contradiction Count** | CC = \|contradictions(K')\| | = 0 |

## 💡 Практические применения

### 1. Автоматическое создание обзоров

**Сценарий:** У вас 50 диссертаций по теме "Deep Learning for Medical Imaging"

**Задача:** Создать обзорную статью для Википедии

**Процесс:**
```python
from knowledge_transformer import DissertationDecomposer, WikiAggregator

# Шаг 1: Декомпозиция всех диссертаций
decomposer = DissertationDecomposer(use_ml=True)
all_segments = []

for dissertation in dissertations:
    segments = decomposer.decompose(dissertation.text, dissertation.metadata)
    all_segments.extend(segments)

# Шаг 2: Агрегация
aggregator = WikiAggregator(target_length=5000)
wiki_article = aggregator.aggregate(all_segments, topic="Deep Learning Medical Imaging")

# Шаг 3: Публикация
publish_to_wikipedia(wiki_article)
```

**Результат:** Автоматически созданная статья с цитированиями всех 50 источников.

### 2. Генерация идей для новых исследований

**Сценарий:** Вы прочитали 20 статей Википедии по смежным темам

**Задача:** Найти пробелы и сгенерировать план диссертации

**Процесс:**
```python
from knowledge_transformer import WikiDecomposer, DissertationSynthesizer

# Шаг 1: Извлечение фактов
decomposer = WikiDecomposer()
all_facts = []

for article in wiki_articles:
    facts = decomposer.extract_facts(article.text)
    all_facts.extend(facts)

# Шаг 2: Построение графа знаний
knowledge_graph = build_knowledge_graph(all_facts)

# Шаг 3: Поиск пробелов
gaps = identify_knowledge_gaps(knowledge_graph)

# Шаг 4: Генерация гипотез
hypotheses = generate_hypotheses(gaps, knowledge_graph)

# Шаг 5: Синтез диссертации
synthesizer = DissertationSynthesizer()
dissertation_plan = synthesizer.synthesize(hypotheses, wiki_articles)

print("Предлагаемая тема диссертации:")
print(dissertation_plan.title)
print("\nОсновные гипотезы:")
for h in dissertation_plan.hypotheses:
    print(f"  - {h.claim}")
```

**Результат:** Готовый план диссертации с обоснованием новизны.

### 3. Рационализация учебных материалов

**Сценарий:** У вас энциклопедическая статья на 20,000 слов

**Задача:** Сократить до 5,000 без потери сути

**Процесс:**
```python
from knowledge_transformer import KnowledgeRationalizer

# Шаг 1: Построение графа знаний
K = extract_knowledge_graph(long_article)

# Шаг 2: Рационализация
rationalizer = KnowledgeRationalizer(
    target_compression=0.25,  # сжать до 25%
    max_information_loss=0.1   # не более 10% потерь
)

K_rationalized = rationalizer.rationalize(K, method='compress')

# Шаг 3: Генерация сокращенной статьи
short_article = generate_text_from_graph(K_rationalized)

print(f"Было: {len(long_article.split())} слов")
print(f"Стало: {len(short_article.split())} слов")
print(f"Потеря информации: {rationalizer.information_loss:.1%}")
```

**Результат:** Сжатая статья с минимальными потерями.

